## Save quick access

Use the ordinary tracker address above, not a link from a sign-in email. Open it directly in Safari or Chrome rather than Outlook's embedded browser. Keep the shortcut name generic, such as “Whiz Kids Tracker”. Menu wording varies by operating system and browser version.

| Device | Home Screen shortcut | Bookmark |
|---|---|---|
| iPhone/iPad, Safari | Open tracker → Share (sometimes under More) → Add to Home Screen → name it → Add. If offered, Open as Web App is optional. Open the new icon and sign in there if asked. | Share → Add Bookmark → choose location → Save. Reopen from Safari's bookmarks. |
| Android, Chrome | Open tracker → three-dot menu → Add to Home screen, or Install and create shortcut → Create shortcut → name it → Add. Confirm placement if asked. | Three-dot menu → Add to bookmarks/star. Reopen from menu → Bookmarks. |
| Computer | A bookmark is usually simplest. | Open tracker → Ctrl+D (Windows) or Command+D (Mac), or use the browser's bookmark/star menu. |

Adding a shortcut does not create offline saving or permission to view records. You still need internet access and an authorised account. A Home Screen web app can require a separate sign-in from the browser. School-managed devices may restrict shortcuts; use an approved bookmark or ask school IT.

## Remove it later

Sign out first. On iPhone/iPad, touch and hold the icon and choose Delete Bookmark, Remove App or Delete App as offered for that shortcut/web app, then confirm. On Android, touch and hold and choose/drag to Remove; if installed as an app, Uninstall removes it from the device. To remove a bookmark, open the browser's bookmarks, find the tracker, and choose Delete (Safari may offer this by holding the bookmark or using Edit; Chrome uses the bookmark's menu).

Removing an icon/bookmark does not delete cloud records or revoke access. Contact Alex to arrange access removal. Do not clear browser data as the first response to a saving problem.

## Common problems

* **No code:** check the authorised address, junk folder and school email quarantine. Wait at least a minute before requesting another, and use only the newest email. Ask school IT about blocked mail if necessary.
* **Email contains only a link:** contact Alex; the email template may need updating. Do not copy digits from the link.
* **Code rejected:** enter all six digits, including any leading zero; check the email address matches. Request a new code if expired. Never forward the code to someone else.
* **Signed in but no participant:** contact Alex to check the authorised email and participant access; signing in alone does not grant access.
* **No Add to Home Screen option:** open the normal address directly in Safari/Chrome. If the device is managed, use an approved bookmark.
* **Save fails or internet drops:** keep the page open, restore the connection and check the recorded day before retrying. Do not assume unsaved entries are retained after closing/reloading. Contact Alex if uncertain.
